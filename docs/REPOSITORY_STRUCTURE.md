## Ownership Rules

| Directory | Owner | May Edit |
|---|---|---|
| `apps/frontend/**` | Lakshya | Lakshya only |
| `apps/backend/**` | Harsh | Harsh only |
| `ai/**` | Ubaid | Ubaid only |
| `contracts/**` | All (frozen) | Any change requires all 3 to agree |
| `data/**` | Shared | Changes should be deliberate and communicated |
| `docs/**` | Shared | Anyone may add docs |
| `scripts/**` | Shared | Anyone may add scripts |
| `.github/CODEOWNERS` | Harsh (team lead) | Harsh only |

## Dependency Direction Rules

- Frontend depends on Backend API and `contracts/experience.schema.json`
- Backend depends on AI output and `contracts/customer-state.schema.json`
- AI depends on `data/` and `contracts/customer-state.schema.json`
- **NO circular dependencies allowed**
- Frontend NEVER imports from `ai/` or `apps/backend/`
- Backend NEVER imports from `apps/frontend/`

## Where Tests Belong

- **Backend tests:** `apps/backend/tests/`
- **Frontend type checking:** `npx tsc --noEmit` in `apps/frontend/`
- **AI pipeline tests:** Run `ai/intelligence/run.py --scenario <name>` and validate output
- **Contract validation:** `jsonschema` validates against `contracts/`

## Where Mocks Belong

- **Frontend mocks:** `apps/frontend/src/mock/`
- These are copies of contract-conforming JSON for offline development
- Updated when contracts change

## Files That Should NEVER Be Edited Concurrently

- `contracts/*.schema.json`
- `data/seed/*.json`
- `data/scenarios/*.json`
- `docker-compose.yml`
- `.env.example`
- `.github/CODEOWNERS`
